Categories

People

Tag jobs by who they belong to (e.g. you and a partner sharing this app). Purely a label - everyone can still see every job, use the owner filter on the Jobs page to narrow the view. Each person can also pick which resume (managed entirely in the resume app's own People admin page) their own "Generate Resume + Cover Letter" tailoring should start from - leave it on the default if this is the only resume the household uses.

Reminders

Push notifications for tasks with a reminder set (see a task's edit form). Per-device - enable this on every phone/browser you want nagged, not just one. iOS needs 16.4+ and this app added to your home screen first (not a regular Safari tab).
